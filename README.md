# Random Task Generator

**Автор:** Шумаков 

## Описание

Приложение для генерации случайных задач с графическим интерфейсом. Позволяет выбирать задачи из предопределённого списка или добавлять свои, фильтровать по типу (учёба, спорт, работа), сохранять историю и список задач в JSON.

## Возможности

- Генерация случайной задачи.
- Добавление новых задач с проверкой на пустую строку.
- Фильтрация задач по типу.
- Сохранение и загрузка данных из файла.
- Ведение истории сгенерированных задач.

## Пример использования

1. Запустите `main.py`.
2. Выберите тип задачи (или оставьте «все»).
3. Нажмите «Сгенерировать задачу» — задача появится в истории.
4. Для добавления своей задачи нажмите «Добавить задачу».
5. История сохраняется автоматически.
